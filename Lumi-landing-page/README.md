# Lumi — Wellness Landing Page

A responsive and interactive landing page for Lumi, a digital wellness platform designed to help users build and maintain better everyday habits.

This project is being developed as part of the *Codveda Technology Front-End Development Internship — Level 1, Task 1*.

📌 Project Overview

Lumi is a wellness platform that helps users develop consistent habits through simple tools such as habit tracking, daily reminders, and progress insights.

The goal of this project is to create a modern, responsive landing page that clearly communicates Lumi's value and encourages visitors to get started.

 🎯 Project Goals

* Create a professional and visually appealing landing page
* Provide a responsive experience across mobile, tablet, and desktop
* Use semantic HTML for accessibility and SEO
* Implement layouts using CSS Flexbox and/or Grid
* Add interactive elements using vanilla JavaScript
* Implement smooth scrolling and basic animations
* Provide a clear call-to-action for visitors

 ✨ Features

* Responsive navigation bar
* Hero section with clear call-to-action
* Features section
* How It Works section
* Call-to-action section
* Responsive footer
* Mobile navigation menu
* Smooth scrolling
* Interactive buttons and elements
* Hover effects
* Basic entrance animations

🛠️ Tools

* HTML5
* CSS3
* Vanilla JavaScript
* Git & GitHub

📱 Responsiveness

The website follows a mobile-first approach and is designed to adapt to:

* 📱 Mobile devices
* 📱 Tablets
* 💻 Desktop screens

Responsive layouts are implemented using CSS media queries.

♿ Accessibility & SEO

The project uses semantic HTML elements to improve accessibility and search engine optimization.

Examples include:

* `header`
* `nav`
* `main`
* `section`
* `footer`
* Descriptive image `alt` attributes
* Logical heading hierarchy

🎨 Design

The design focuses on creating a clean, modern and approachable wellness experience.

Design considerations

* Consistent typography
* Clear visual hierarchy
* Accessible contrast
* Consistent spacing
* Responsive layouts
* Interactive states for buttons and cards
